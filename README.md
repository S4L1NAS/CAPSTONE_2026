# Capstone 2026 — Equipo BPB

## Sistema web de Obras, Mantención y Mejoras
**Hotel & Centro de Eventos El Almendro**

Proyecto académico de Ingeniería en Informática, Duoc UC. Desarrollamos una plataforma web para centralizar el registro y seguimiento de mantenciones, obras, mejoras, solicitudes y actividades operativas del hotel.

## Tecnologías

HTML, CSS, JavaScript, Supabase, PostgreSQL, Vercel, GitHub y Jira.

Trabajamos con **Scrum** para organizar las actividades en sprints. Las tres fases del repositorio corresponden a las etapas académicas de Capstone, no a sprints.

La documentación distingue entre funcionalidades desarrolladas, pruebas registradas y validaciones pendientes. La existencia del código y de los archivos de entrega no acredita por sí sola la aceptación final del representante del hotel.
